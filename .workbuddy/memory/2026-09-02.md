## 通读 sky-take-out-AI 项目（117 个文件），目标：作为求职 Java 开发的简历项目进行完善

### 项目定位
苍穹外卖 + Spring AI 的「AI 外卖点餐助手」。Spring Boot 3.5.13 / JDK17 / Spring AI 1.1.6 /
DeepSeek 对话模型 / 阿里百炼 text-embedding-v4 / MyBatis-Plus 3.5.7 / Redis + Redisson /
SimpleVectorStore / Kryo / Knife4j / iText9 / OkHttp / Jsoup。

### 核心链路
ChatController(SSE) → RouterAgent（LLM 选 Skill + 分类 SIMPLE_CHAT / AMBIGUOUS / COMPLEX_TASK）
→ COMPLEX_TASK 走 PlanExecute：decomposeTaskWithContract 拆子任务 → buildExecutionWaves 拓扑分层
→ 每子任务一个 Kanodays88Manus（BaseAgent ← ReActAgent ← ToolCallAgent）跑 ReAct，上限 5 步
→ distillSubTaskResult 蒸馏（>2000 字符才蒸馏）→ fuseResults 汇总。

### 可写进简历的亮点
1. Plan-and-Execute + 子任务契约（downstreamTaskIds / coreContent）解决「蒸馏丢下游信息」
2. 拓扑分层并行（buildExecutionWaves + CompletableFuture）
3. Anthropic Agent Skill 三层渐进式上下文（SkillLoader → SkillRegistry → LoadReferenceTool）
4. 自制 ReAct 循环 + 步数预算 + 卡死检测（重复 3 次触发）
5. 上下文蒸馏双副本（structuredCoreResult 进上下文 / rawResult 归档兜底）
6. Kryo + ThreadLocal 的文件持久化会话记忆，Redis 维护 TTL，定时任务清理向量
7. WebSearchTool 内用临时 SimpleVectorStore 对搜索结果做 RAG 二次提纯
