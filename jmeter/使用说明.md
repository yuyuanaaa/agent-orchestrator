# JMeter 压测脚本 · 使用说明

> 目标：测出简历里缺的 4 个数字 —— **P95 / TPS / 缓存命中率 / 稳定并发**
> 对象接口：`GET http://localhost:8080/api/ai/shop/dish/list`（走 Cache-Aside + Redisson 分布式锁）
> 全部脚本已按本项目实配写好，**你只需要装 JMeter 并改一行路径**。

## 目录内容

| 文件 | 作用 |
|---|---|
| `dish-list.jmx` | 压测脚本（自动登录取 token → 并发打菜品查询接口） |
| `run-test.bat` | 一键运行，自动生成 HTML 报告（含 P95 / TPS / 错误率） |
| `redis-hit-rate.bat` | 取 Redis 缓存命中率（压测前后各跑一次） |
| `使用说明.md` | 本文件 |

## 一、准备工作（只需做一次）

### 1. 装 JMeter

1. 下载：https://jmeter.apache.org/download_jmeter.cgi → 选 `apache-jmeter-5.6.3.zip`
2. 解压到任意目录，例如 `C:\apache-jmeter-5.6.3`
3. **改一行**：用记事本打开 `run-test.bat`，把
   ```
   set "JMETER_HOME=C:\apache-jmeter-5.6.3"
   ```
   改成你实际的解压路径。

> JMeter 需要 Java（你本机已有 JDK 17，没问题）。

### 2. 启动依赖（MySQL + Redis）

双击桌面 **Docker Desktop**，等左下角状态变绿。然后在项目根目录执行：

```bash
docker compose up -d mysql redis
```

Redis 容器名是 `agent-redis`，脚本里已经写死了这个名字。

### 3. 启动后端（免 API Key 的 mock 模式）

在项目根目录（`AiProject-master`，含 `pom.xml` 的那层）执行：

```bash
mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=mock
```

看到日志出现 `Started AgentPlatformApplication` 就成功了。**这个窗口不要关。**

## 二、跑压测

### 第 1 步：记录压测前的 Redis 统计

双击 `redis-hit-rate.bat`，会输出类似：

```
keyspace_hits:1234
keyspace_misses:56
```

**把这两个数抄下来**（这是「before」）。

### 第 2 步：跑压测

双击 `run-test.bat`。默认 **100 并发 / 持续 60 秒**，跑完会自动打开报告。

想改并发数或时长，编辑 `run-test.bat` 里的：

```bat
set THREADS=100
set DURATION=60
```

### 第 3 步：记录压测后的 Redis 统计

压测结束后，**再双击一次** `redis-hit-rate.bat`，抄下新的两个数（这是「after」）。

### 第 4 步：算缓存命中率

```
命中率 = (hits_after - hits_before) ÷ [ (hits_after - hits_before) + (misses_after - misses_before) ]
```

例如 before = 1000/50，after = 11000/450：

```
命中 = 11000 - 1000 = 10000
未命中 = 450 - 50 = 400
命中率 = 10000 ÷ 10400 = 96.2%
```

## 六、常见问题

**Q：报告里全是红色错误 / Error 100%？**
大概率是后端没起来，或者 token 没拿到。检查：
1. 后端窗口是否显示 `Started AgentPlatformApplication`
2. 单独访问 http://localhost:8080/api/ai/shop/dish/list 看看（应该返回 401，说明服务活着）
3. 用 GUI 打开 `dish-list.jmx`，看 setUp 登录请求是否返回 200

**Q：为什么脚本要先登录？**
因为 `/ai/shop/**` 走 `LoginInterceptor`，只有 `/ai/user/login` 免鉴权。脚本用 setUp 线程组登录一次，把 token 提升为全局属性供所有并发线程复用。

**Q：测试用户是谁？**
脚本用 `jmeter_user` / `test123456` 自动注册（后端「未注册自动注册」）。用户名只含字母和下划线，符合项目路径白名单 `[A-Za-z0-9_-]`。

**Q：压测会把数据库搞乱吗？**
不会，只打查询接口。但会往 `user` 表插一个 `jmeter_user` 测试账号，介意的话压测完手动删掉。

**Q：能不能不装 JMeter？**
可以，但 JMeter 是行业标准，面试官默认你会用。装一次只要 5 分钟，建议装。
